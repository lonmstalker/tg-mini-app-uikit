# План: showcase-лендинг tg-mini-app-uikit

Маркетинговая витрина кита: одностраничный лендинг с живыми интерактивными
демо, построенный **на самом ките** (dogfooding). Не заменяет `docs/site`
(справочник) и Storybook (каталог) — дополняет их и ссылается на оба.

**Статус:** реализовано: marketing landing — в корне, interactive showcase
(T1–T8) — на `/demo/`. Осталось вручную:
включить `deploy-site.yml` (заменяет Pages-деплой из `docs.yml`) и прогнать
сайт в Telegram WebView через туннель (п. 7).
**Оценка:** 8 слайсов ≈ 5–6 дней чистой работы. Каждый слайс = отдельный
коммит с полным циклом (код → живая проверка → e2e где заявлено → коммит).

---

## 1. Цели и не-цели

Цели:

- За 10 секунд донести «что это и почему это хорошо»: iOS-ощущение,
  Telegram-интеграция, перф-дисциплина, доступность.
- Дать потрогать компоненты прямо на странице (жесты включая pinch-zoom,
  темы, локали, знобы кастомизации) без установки чего-либо.
- Единая точка входа: лендинг → Storybook (каталог) → docs (справочник) → npm.

Не-цели:

- Не второй Storybook: максимум ~15 самых зрелищных компонентов.
- Не документация: ни одной страницы API, только сниппеты-тизеры.
- Не блог/CMS/аналитика. Одна статическая страница.

## 2. Архитектура и инфраструктура

- Новый workspace **`examples/showcase`**: Vite + React 19 +
  `tg-mini-app-uikit` (workspace-link). **Ноль новых runtime-зависимостей**:
  движение — токены кита + CSS + WAAPI; скролл-появления — IntersectionObserver.
- Одна страница, без роутера. Секции — якоря (`#features`, `#components`).
- Сборка: `vite build` → `examples/showcase/dist`, `base` конфигурируется
  (GH Pages поддиректория `/tg-mini-app-uikit/`).
- Корневые скрипты: `site:dev` (порт 5175), `site:build`, `site:deploy`
  (собирает лендинг + `storybook-static` → `/storybook` + docs → `/docs`
  в один артефакт для GitHub Pages; GitHub Actions workflow `deploy-site.yml`
  на пуш в main — вручную включаемый).
- `.claude/launch.json`: запись `showcase` (порт 5175).
- Гейты: `check:animatable` расширить на `examples/showcase/src`;
  новый Playwright-проект `showcase` (smoke, см. T8) + поднять floor в
  `check-e2e-count.mjs` с объяснением.

## 3. Дизайн-направление

- **Тема:** тёмная по умолчанию (медиа-вьюер, glass и тени выигрышнее);
  переключатель light/dark в шапке — он же живое демо темизации.
  Уважать `prefers-color-scheme` при первом заходе.
- **Типографика:** системный стек кита (SF Pro/Segoe/Roboto). Hero-заголовок
  `clamp(40px, 8vw, 76px)`, вес 800, letter-spacing −0.02em. Секционные
  заголовки `--tk-fz-large`. Текст `--tk-fz-body`, `--tk-text-2`.
- **Сетка:** контейнер max-width 1080px, паддинги `--tk-sp-4`;
  mobile-first — эталонная ширина **375px** (кит про мобильные приложения,
  идеальный вид на телефоне обязателен), брейкпоинты 768/1080.
- **Цвет:** только `--tk-*` токены. Фон — `--tk-bg` + 2–3 неподвижных
  radial-градиентных пятна `--tk-accent-06/12` (без анимации фона — paint diet).
- **Телефон-фрейм:** переиспользовать стиль device-frame из Storybook
  (скруглённая рамка, чёлка), внутри собственный `TKProvider` со своей темой,
  чтобы Tweaks и переключатели красили и его.
- **Глубина:** карточки `--tk-surface` + `--tk-shadow-sm`, hover →
  `--tk-shadow-md` (только `@media (pointer: fine)`).
- **Язык сайта:** английский (аудитория npm), но секция i18n живьём
  переключает строки кита en/ru — это фича-демо.

## 4. Система движения страницы

Всё подчиняется правилам кита: transform/opacity only, длительности/изинги —
токены, оба reduced-motion пути глушат всё.

| Паттерн | Механика | Где |
|---|---|---|
| Scroll-reveal | хук `useReveal`: IntersectionObserver (threshold 0.2, once) ставит класс; CSS `opacity 0→1, translateY(24px)→0, var(--tk-t3) var(--tk-ease)`; stagger — `transition-delay` инлайн (индекс × 60ms) | все секции |
| Каскад hero | `tk-rise` с delay 0/60/120ms на строках заголовка; фрейм — `tk-pop-lg` | hero |
| Автосценарий | конечный автомат на цепочке таймеров, шаги через **публичные controlled-пропсы** компонентов (не синтетические клики); пауза при `document.hidden`; при reduced motion не стартует (статичный кадр) | hero-фрейм |
| Hover-lift | `translateY(-2px)` + тень, `--tk-t1`; на таче вместо него `tk-press` | бенто-плитки |
| Живые демо-анимации | гейт через IntersectionObserver: демо (marquee, конфетти, шиммер) не работают вне вьюпорта | преимущества, бенто |
| Счётчик коммитов | обёртка `<Profiler>` пишет число в бейдж — визуализация перф-контракта | карточка «перф» |

Запрещено: параллакс на скролле (JS на скролл-фрейме), бесконечные фоновые
анимации, layout-свойства в transition/keyframes (гейт `check:animatable`).

## 5. Структура страницы (сверху вниз)

1. **Шапка** (sticky, `--tk-glass` + blur): логотип-словоmark, якоря секций,
   переключатель темы, GitHub-ссылка. Скрывается ниже 768px до бургер-меню?
   Нет — просто логотип + тема + GitHub (минимализм).
2. **Hero:** слева заголовок «iOS-flavored UI kit for Telegram Mini Apps»,
   подзаголовок (zero deps, React 18/19, Bot API 9.6), `npm i tg-mini-app-uikit`
   с кнопкой копирования (toast кита), бейджи (~60 kB brotli, 1235 tests,
   MIT). Справа телефон-фрейм с автосценарием «кошелёк»: скролл галереи →
   sheet открылся/закрылся → пин 1-2-3-4 → зелёный pop → конфетти → пауза →
   цикл (~15 с). CTA: «Get started» (docs) + «Browse components» (Storybook).
3. **Преимущества** — 4 карточки, каждая с живым мини-демо:
   - *Native-feel gestures* — мини-sheet во фрейме, который можно таскать пальцем;
   - *Telegram out of the box* — переключатель light/dark/tg-theme, красящий
     карточку + мок MainButton;
   - *Compositor-only motion* — демо-анимация + живой счётчик React-коммитов
     (= 0 во время жеста) и строка «enforced by CI»;
   - *Accessible by default* — фокус-обводки, aria-live демо, скринридер-строки.
4. **Бенто-стена компонентов** (~12 плиток, разноразмерная сетка):
   ImageViewer (открывается настоящий, с pinch), PinInput (success/error),
   Gallery, NoticeBar (marquee), Chat-шаблон, Confetti (по клику), Sheet,
   Calendar, OTP, Slider, Skeleton-группа, Switch+Chips. На каждой плитке —
   ссылка «Storybook →» на её story.
5. **Tweaks-панель** (липкая секция): акцент (5 пресетов + color input),
   радиус `--tk-rx`, скорость `--tk-ms`, шрифт `--tk-fz`, кнопка Reset.
   Красит **всю страницу**, включая hero-фрейм. Персист в localStorage.
6. **i18n + код** — два таба-блока: переключатель en/ru, меняющий строки кита
   во всех живых демо страницы (`TKLocaleProvider` вокруг всего) + сниппеты
   Install / Theme / Telegram с копированием (источник — getting-started).
7. **Футер:** Storybook, Docs, GitHub, npm, версия пакета (из package.json
   на этапе сборки), MIT.

## 6. Задачи

### T1 — Каркас и деплой
`examples/showcase` (vite.config с base, index.html: meta/OG/favicon, main.tsx,
секции-заглушки), корневые скрипты `site:dev`/`site:build`, launch.json,
workflow `deploy-site.yml` (лендинг + storybook + docs в один Pages-артефакт).
**Приёмка:** `npm run site:dev` поднимает страницу; `site:build` выдаёт
рабочую статику с правильным base; workflow собирает артефакт в dry-run;
375px без горизонтального скролла.

### T2 — Дизайн-система страницы
Компоненты `Section`/`Container`/`SectionTitle`, хук `useReveal`, фоновые
пятна, sticky-шапка с blur и переключателем темы, футер.
**Приёмка:** reveal играет один раз со stagger, мгновенен при reduced motion
(оба пути); тема переключается без перезагрузки и уважает prefers-color-scheme;
шапка не перекрывает якорные заголовки (scroll-margin-top).

### T3 — Hero + автосценарий
Заголовок-каскад, install-команда (копирование → toast кита), бейджи, CTA,
телефон-фрейм с «кошельком», автомат сценария (хук `useScenario` с полным
cleanup таймеров).
**Приёмка:** ≥3 цикла без утечек (таймеры/слушатели сняты при unmount);
`document.hidden` ставит на паузу; reduced motion → статичный кадр без
автозапуска; LCP hero-текста не ждёт сценарий; копирование работает.

### T4 — Секция преимуществ
4 карточки с живыми демо и IntersectionObserver-гейтом автодемо.
**Приёмка:** каждое демо интерактивно и клавиатурно-доступно; вне вьюпорта
демо-анимации стоят; счётчик коммитов показывает 0 во время драга sheet.

### T5 — Бенто-стена
12 плиток, ленивый монтаж тяжёлых демо (IO), ссылки в Storybook.
**Приёмка:** ImageViewer открывается с лендинга и pinch/double-tap/swipe-close
работают; конфетти по клику; мобильная сетка — 1 колонка; ссылки ведут на
правильные story-URL.

### T6 — Tweaks-панель
Знобы accent/radius/motion/font + Reset, персист localStorage.
**Приёмка:** изменение красит все секции включая hero-фрейм мгновенно;
значения переживают перезагрузку; Reset возвращает дефолт; невалидный
localStorage не роняет страницу.

### T7 — i18n-демо и сниппеты
Переключатель en/ru через `TKLocaleProvider` вокруг всей страницы; табы
сниппетов с копированием.
**Приёмка:** переключение меняет строки кита во всех живых демо (пин,
вьюер-счётчик, NoticeBar close); сниппеты компилируются (проверить в
scratch-файле с typecheck) и соответствуют текущему API.

### T8 — Полировка и гейты
OG-картинка (скриншот hero), SEO-мета, Lighthouse-прогон, Playwright-проект
`showcase` (3–4 smoke: страница рендерится без console.error; тема
переключается; вьюер открывается/закрывается; Tweaks красит), поднять
e2e-floor, аудит reduced-motion и 375px, `check:animatable` на showcase/src.
**Приёмка:** Lighthouse mobile: Perf ≥ 90, A11y ≥ 95, SEO ≥ 90; e2e зелёные;
`git grep -nE '#[0-9a-fA-F]{3,8}' examples/showcase/src` — только токены
(исключая OG/favicon ассеты); полный проход по чек-листу движения (п. 4).

## 7. Мелкие детали (не забыть)

- `<html lang="en">`, skip-link «Skip to components», landmark-роли секций.
- Кнопка копирования: `navigator.clipboard` + фолбэк `execCommand`; фидбэк —
  toast кита, не alert.
- Версия пакета в футере — импорт из `package.json` на этапе сборки
  (define), не runtime-fetch.
- Автосценарий не перехватывает пользовательский ввод: первый же pointerdown
  внутри фрейма останавливает автомат до конца сессии.
- `content-visibility: auto` на нижних секциях — дешёвый первый рендер.
- Никаких внешних шрифтов/CDN — весь сайт работает офлайн после загрузки.
- Favicon — SVG-эмодзи (⚡ или 📱), OG 1200×630.
- В шапке у GitHub-ссылки `rel="noopener"`, `aria-label`.
- Storybook-ссылки строить от `import.meta.env.BASE_URL` (работают и локально,
  и на Pages).
- Проверить сайт внутри Telegram WebView (через ngrok/туннель) минимум один
  раз перед объявлением готовности: safe-area, тема, жесты.

## 8. Риски

| Риск | Митигция |
|---|---|
| GH Pages base-path ломает ссылки/ассеты | `base` в vite + относительные URL, e2e-smoke на собранной статике |
| Автосценарий течёт таймерами при HMR/unmount | единый `useScenario` с AbortController-семантикой; проверка в T3 |
| Тяжёлые демо портят LCP | ленивый монтаж ниже фолда (IO), hero-фрейм — лёгкие компоненты |
| ImageViewer в потоке страницы конфликтует со скроллом | он модальный (scroll lock уже в ките) — конфликт исключён |
| Слишком «шумная» страница | правило: в вьюпорте одновременно ≤1 автоиграющее демо |

## 9. Порядок и зависимости

T1 → T2 → T3 → (T4, T5 параллельно) → T6 → T7 → T8.
Коммиты: `feat(showcase): …` по слайсу. После T3 и T5 — промежуточный деплой
на Pages для живой обратной связи.
